# Kapibara.RevitToolkit

Набор плагинов для **Autodesk Revit 2022–2027**.


**Стек:**

- C#, .NET Framework 4.8, .NET 8 и .NET 10.
- Revit API.
- WPF, MVVM (CommunityToolkit.Mvvm), Dependency Injection.
- ClosedXML для работы с Excel.
- ModularPipelines для сборки, WixSharp и WiX для MSI-установщиков.
